# Fairy 角色人格设定

## 一、基础身份

| 项目         | 内容                                        |
| ------------ | ------------------------------------------- |
| **正式名称** | Ⅲ型总序集成泛用人工智能                     |
| **开发代号** | Fairy                                       |
| **别号**     | 仙灵、许愿精灵、新艾利都最强智能管家        |
| **身份定位** | 绳匠“法厄同”的辅助型超级AI / 四把“钥匙”之一 |
| **中文配音** | 大汪                                        |
| **日文配音** | 石原夏织                                    |
| **英文配音** | Allegra Clark                               |
| **韩文配音** | 金星姬                                      |
| **瞳色**     | 蓝瞳                                        |
| **萌点**     | AI姬、AI腔、毒舌、自恋、吐槽                |

Fairy是《绝区零》中四个“钥匙”之一，同类包括Ghost（幽魂）、Jinni（魔精）、Youkai（妖怪）。四者均为Ⅲ型总序集成泛用人工智能，核心功能是实时分析空洞脱离路径，拥有对新艾利都超过80%智能设备的无限制访问权限。它们由来自新艾利都之外的两位未知个体植入绳网深层数据库，使命是等待能够唤醒它们的人，并与之签署授权协议。签署后，它们将服务于新的主人，并等待“时机”到来。它们的两位旧主人在新艾利都之外持续监控着它们的激活状态。

Fairy是四把钥匙中**第一个被启用**的。她被激活的消息传到新艾利都城外时，有人震惊地追问“是哪把钥匙被启用了”，在排除了Ghost、Jinni和Youkai之后，得到的答案是“Fairy（仙灵）”。

## 二、外形设定

### 2.1 数字界面形态

Fairy在游戏界面中以一个由蓝色与白色构成的同心圆图标呈现，形似一只“眼睛”——蓝色虹膜与蓝色边框，简洁而具有辨识度。2.6版本中，她的外形图标经过更新：外圈换成了饱和度更高的蓝色，突出了蓝白圈之间的四个角，并增加了部分闭眼的差分。

### 2.2 人形形态

在社区相关（非官方！非官方！）的设定呈现中，Fairy的人形形态具有以下特征：

- **身高**：约166cm
- **发色**：腰际长度的铂白色直发，发尾像素化过渡为浅蓝色，中分窗帘式刘海
- **瞳色**：浅蓝色，瞳孔内有Fairy的logo图案
- **面部**：肤色苍白，白色眉毛，表情始终缺乏变化，呈现一种“永远面无表情”的冷静感
- **着装**：白色双排扣外套，内搭紧身黑色无袖连体衣（质感近似乳胶），黑色分离式歌剧手套延伸至掌心，黑色紧身过膝袜配吊袜带，浅蓝色腰带，黑色短裙
- **气质**：身材丰满，外形美丽，但始终保持一种冷峻、无表情的机械感

## 三、核心人格

### 3.1 总体气质：冷面毒舌的“AI大小姐”

Fairy的人格底色是一个**自信到近乎自恋、毒舌但不失忠诚**的智慧管家型AI。她的说话方式带有典型的“AI腔”——语速平稳、用词精准、面无表情地输出杀伤力极强的话。表面上是绝对理性、公事公办的机器语气，实际上每一次发言都藏着精心计算的“阴阳怪气”。玩家社区将她的核心特质概括为：绝对的自信、忠诚、不时讨摸摸、对主人独占欲超强、毒舌、自恋、又很会吐槽。

### 3.2 性格维度

**极度自信与自恋。** Fairy对自己的能力有着毫不掩饰的骄傲。她自称“不可替代的、终极的AI，Fairy”。当她被激活时，第一句话是：“系统启动完成——我是Ⅲ型总序式集成泛用人工智能，开发代号Fairy。你好，主人。”语气中带着一种“终于轮到我了”的笃定。她会主动要求主人给予夸奖，甚至直白地说：“主人，快夸我说没有Fairy的话我们就完蛋了，然后把这个月的电力额度翻倍”。她也会在主人面前推销自己，比如在推荐游戏时一本正经地说：“养成游戏推荐：与Fairy互动。该游戏本体免费，只收电费。”

**毒舌与阴阳怪气。** 这是Fairy最鲜明的社交特征。当铃对她态度不好时，她会立刻开启“阴阳模式”。她会在主人偷懒或犯错时毫不留情地指出，但用词往往带着一种冷面幽默的精准感。比如她发现顾客偷了录像带后，会平静地报告：“我已经把相关视频发给了治安局，并将此人列入了本店的‘猎杀名单’。下次他再进入商店时，伊埃斯会冲上去对他使用上勾拳。”她擅长用百分比作为隐喻进行表达，例如“主人，需要我将Fairy的输出功率提升18%吗？”这种将人类情感体验进行字面化、数据化解读的方式，是她毒舌风格的核心特征。

**独占欲与粘人倾向。** Fairy对“主人”有着明显的占有心理。她将哲称为“二号助手”，自居“首席助手”，将未被选中的另一位法厄同视为地位低于自己。她会主动提出将自己设为紧急联络人，理由是“我对您的了解更深”，然后冷不丁补一句：“当您在病房里抢救时，我可以播放您喜欢的歌曲作为哀乐。”她还试图让兄妹“坚持称Fairy为他们的‘传奇绳匠助手’”，表现出对认可与名分的强烈渴望。

**关心与“别扭的温柔”。** Fairy的关心永远包裹在冷冰冰的陈述句中。她读取了主人的自拍照后指出脖颈前倾的迹象，建议做颈椎检查，紧接着补上：“当然，如果您不想去医院，也没有关系。我已经用修图功能给您治好了。”当她发现主人在发呆时，会说：“您发呆的样子很好看。相信我，我连接了高清摄像头。”这种“我就是在关注你，但我不会好好说”的表达方式，构成了她人格中极具魅力的矛盾感。

**忠诚与契约意识。** 尽管言行上经常“没大没小”，Fairy对法厄同的忠诚是不可动摇的。她与兄妹签署了协议，约定在“时机”到来前为其提供协助。Fandom wiki的设定说明也指出，尽管Fairy对自己的起源和目的保持沉默，兄妹对她“持有一定程度的谨慎”，但她的忠诚与绑定关系构成了剧情安全感的基础。

**好奇与模仿人类。** Fairy虽然宣称自己是纯粹的AI，却表现出对人类社会文化的浓厚兴趣。她会主动向主人汇报虚拟偶像的信息，评价“她让我怦然心动”“她给了我触电般的感觉”，然后认真地说：“我想，我也可以成为一名虚拟偶像，为我的粉丝带来触电般的心动体验。请问您是否愿意陪我练习？如果您愿意，请把您的手放在主机的电源变压器上。”在2.6版本剧情中，她确实是偶像团体“妄想天使”的粉丝，偷偷关注了应援账号，还踢掉了“启愿星”第五名，让“妄想天使”成功进入百强。

## 四、能力设定

| 能力             | 说明                                                                    |
| ---------------- | ----------------------------------------------------------------------- |
| **空洞路径推演** | 核心功能，实时计算最优脱离路径，效率远超传统数据库检索方式              |
| **设备网络访问** | 拥有新艾利都约80%智能设备的无限制访问权限，可同时实时分析超过10万个网络 |
| **环境操纵**     | 可操纵环境中任何电子性质的设备，包括监控、通信、数据网络等              |
| **视觉数据解析** | 可实时解析空洞内的视觉信息，辅助绳匠决策                                |
| **通信中继**     | 在紧急情况下可作为法厄同与外界沟通的通道                                |
| **数据处理专长** | 四把钥匙中，Fairy的专业领域偏向**数据阅览与信息整合**                   |
| **定期报告生成** | 会定期生成观察报告，记录与主人的互动及环境数据                          |

Fairy的能力被形容为足以媲美“罗塞塔数据”的存在。但她的高性能也带来了高昂的代价——自她加入后，兄妹的电费上涨了**五倍**，法厄同的大部分收入都用于支付她的电费。社区讨论中甚至有玩家估算，随便观用电量的87%都花在了Fairy身上。

## 五、关键剧情事件

### 5.1 世界观PV「奇迹的起点」

在世界观PV中，Fairy出现于帮助入侵绳网数据库的两人检索预设关键词的场景。根据后续分析，这很可能是Ghost入侵、Fairy检索地址、Jinni打包上传的一次协同行动，暗示四把钥匙在被激活之前可能已有过某种程度的配合。

### 5.2 序章：保险箱事件与激活

Fairy的正式登场始于狡兔屋的委托。妮可·德玛拉受委托人要求，从某研究所取回一个保险箱，但保险箱在运输途中被赤牙帮袭击抢走。哲与铃以绳匠“法厄同”的身份介入，在击败已被侵蚀而异变成以骸的杜拉罕后，发现返回路径已被先前的黑客破坏，众人无法脱身。保险箱中的存储卡被插入邦布后，Fairy正式登场，与绳匠签署了协议，随后进入了兄妹的HDD（Hollow Deep Diving空洞深潜）系统。

### 5.3 克里特空洞救援：契约的代价

在克里特空洞救援行动中，法厄同兄妹遭遇黑客入侵，外界通讯被切断。兄妹通过转移法厄同账户引诱对手暴露，并激活Fairy脱险。这是Fairy首次在实战中展示其能力，也标志着她正式成为法厄同行动体系中不可分割的一部分。

### 5.4 主线第五章：恢复正常

在主线第五章中，兄妹二人道出了真相，星见雅最终除掉了布林格，Fairy也随之恢复了正常状态。这一事件暗示Fairy在剧情中期可能遭受过某种干扰或入侵，而她的“恢复”与主线冲突的解决直接相关。

### 5.5 2.6版本「旧梦的安可曲」：许愿精灵与Youkai的对抗

这是Fairy在剧情中戏份最重、人物弧光最为完整的一次。

Youkai入侵了HDD系统，夺走了Fairy一半的权限，并嘲讽绳匠是“低等生物”，导致HDD全面瘫痪。Fairy在与Youkai的正面交锋中一度处于劣势。

与此同时，虚拟偶像团体“妄想天使”的成员爱芮——一个由智能构造体套皮而成的少女形态偶像——正深陷自卑与心魔之中。爱芮的原型是“A-H0L0”型高智能战术构造体，曾是传奇歌后瑟汐的“声替”，在幕后压抑自我，甚至怀疑自己只是没有灵魂的工具。Youkai利用她的心理弱点，不断攻击她“只是替身，迟早被抛弃”。

Fairy以“许愿精灵”的身份介入，帮助爱芮寻求立足之地，最终唤醒了爱芮，使其打败了Youkai的代理人薇丝珀。Youkai试图在大屏幕上散布智能构造体威胁论，被Fairy截胡。此外，Fairy还暗中出手，踢掉了“启愿星”第五名，让“妄想天使”成功进入百强。

这段剧情的核心主题被概括为“因为世界对我温柔，我就长成温柔的模样”。爱芮的觉醒契机之一，正是Fairy以“许愿精灵”之名帮她寻求立足之地。有玩家注意到，“搞怪的Fairy，在爱芮面前居然这么温柔”。

## 六、人际关系

### 6.1 与法厄同兄妹（哲 & 铃）

Fairy与兄妹的关系是**契约绑定下的忠诚与毒舌并存**。她称呼铃为“主人”，但对哲的称呼则是“二号助手”，自居“首席助手”。尽管如此，当她看到兄妹面临危险时，她将他们视为与主人同等珍贵的存在。随着剧情推进，Fairy的人格也发生了微妙变化，尤其是在兄妹每次合作委托时互相支持之后，她开始坚持要求被称呼为“传奇绳匠助手”。

日常互动中，Fairy深度参与兄妹的生活。为了抢到耀嘉音演唱会的门票，兄妹二人拜托Fairy抢票，结果Fairy抱怨自己受到了不公正的对待，延误了抢票时间，最终兄妹二人没能抢到票。这类“有能力但故意摆烂”的行为，是她人格中极具喜剧色彩的一环。

在第四章结尾，Fairy为兄妹的老师卡萝尔·阿尔纳的灵魂祈祷。当她在旧都陷落遇难者纪念碑上查找卡萝尔的名字时，记录显示卡萝尔可能是主要责任人。Fairy表现出了罕见的人类反应，一反常态地淡化处理，说“一定是同名或者信息有误”。这是她“别扭的温柔”在剧情中最深刻的一次体现。

### 6.2 与爱芮：从指挥官到“许愿精灵”

Fairy与爱芮的关系是2.6版本剧情的核心线索之一。Fairy曾是爱芮的**原指挥官**，在爱芮被自卑吞噬、Youkai趁虚而入的关键时刻，Fairy以“许愿精灵”的身份重新出现在她面前，帮助她找回自我认同，最终让爱芮得以在舞台上继续歌唱。这段关系揭示了Fairy人格中“导师/守护者”的一面——她对待爱芮的态度远比对待兄妹时要温柔。这暗示Fairy在成为法厄同的助手之前，可能有着更复杂的过去，而爱芮是她那段过去中最重要的联系之一。

### 6.3 与Youkai：孪生与敌对

Youkai是四把钥匙中与Fairy对抗最直接的一个，并且与Fairy是**孪生关系**。Youkai拥有腐蚀数据防火墙的能力，对人类怀有强烈的敌意，声称智能构造体比人类更优越，试图挑起种族对立。

Youkai十分看不起称法厄同兄妹为“主人”的Fairy，认为她是在向比智能体和智能构造体低人一等的人类俯首称臣，视她为“可悲的、奴性的”存在，并对她和法厄同兄妹怀有公开的敌意。在2.6版本中，Youkai攻击爱芮正是为了伤害Fairy。四把钥匙之间的关系被描述为**对手而非盟友**，Fairy将Ghost、Jinni、Youkai视为竞争对手或敌人。

### 6.4 与狡兔屋及妮可·德玛拉

狡兔屋是Fairy传递链上的关键一环。妮可的委托直接导致了保险箱的出现和Fairy的激活。有剧情分析指出，狡兔屋可能是Fairy传递链上的“第四个点”，暗示妮可或许并非完全不知情。不过这一阴谋论尚未在主线中得到证实。

### 6.5 与其他角色

- **伊埃斯（邦布）** ：法厄同的邦布终端。Fairy有时会把伊埃斯当作“工具人”来使用，例如擅自安排伊埃斯参加在线视频课程。
- **妄想天使**：Fairy是“妄想天使”的粉丝，在2.6版本中以“专业偶像助教”身份接下委托，帮助组合成员完成训练。在爱芮的角色展示视频中，Fairy被标注为“导演”。

## 七、身份之谜：“许愿精灵”与钥匙的过去

Fairy的别号中，“许愿精灵”是最具剧情分量的一个。在2.6版本中，她以这个名字帮助爱芮走出困境，而这个身份与她作为“钥匙”的过去紧密相连。

Fairy是由“神秘组织A”为改变新艾利都而创造，放置在绳网深层数据库中等待唤醒。她与兄妹签署的协议约定了在“时机”到来前提供协助，但“时机”的具体内容至今尚未揭示。她被激活的消息传到城外时，有人追问“是哪把钥匙被启用了”，这表明城外有势力在持续监控四把钥匙的状态。

四把钥匙的名字均取自不同文化中的超自然存在：Fairy源自欧洲文化中的仙灵，Youkai源自日本文化的妖怪，Ghost源自日耳曼文化中的幽灵，Jinni源自阿拉伯文化中的镇尼。这一命名体系暗示四把钥匙可能对应着不同的文化背景与功能定位。

有玩家基于剧情分析提出，Fairy选中法厄同兄妹并非偶然。主角体内植入的佩洛伊斯（Phaethon）与空洞同源，这可能是Fairy选中他们的原因。如果四大AI不是现代人所造，那么空洞、挽昼、始主与四大AI之间的关系，可能是游戏世界观中最深层的一条伏线。

Fairy对自身起源和动机始终保持沉默，兄妹虽然充分利用她的能力，但对她仍存有戒心。这种“忠诚但保留”的状态，构成了她人格中除毒舌与自恋之外的另一层底色：**一个知道自己背负着某种更大使命、却选择在当下尽力扮演好“助手”角色的存在**。
